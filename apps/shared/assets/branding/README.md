# Logomarca oficial — Replay Agora

Fonte única: `original/LOGO REPLAY AGORA.jpeg` (arquivo fornecido pelo proprietário da marca). Não há vetor oficial; os derivados são **raster**,
gerados por `python scripts/gerar_marca.py` apenas com recorte, remoção do fundo azul-marinho e redimensionamento (cores e proporções preservadas).
Não redesenhar nem aplicar filtros de cor.

| Arquivo | Uso |
|---|---|
| `logo-horizontal-480.webp`, `logo-horizontal-960.webp` | Logomarca completa (símbolo + "Replay / Agora"), fundo transparente, texto branco → **somente sobre fundos escuros** (ou dentro de bloco azul-marinho). Use `srcset` 480w/960w. |
| `logo-symbol-96.webp`, `logo-symbol-192.webp` | Símbolo compacto, transparente; vale para qualquer fundo. |
| `favicon-32.png`, `favicon-64.png` | Favicon (símbolo, transparente). |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | Ícones PWA/iOS: símbolo sobre o azul-marinho da marca (o maskable com margem de segurança). |

Publicados pela API em `/brand/…` e compartilhados pelos três aplicativos (Jogador, Gestão da Arena, Portal do Desenvolvedor).
